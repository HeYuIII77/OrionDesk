# OrionDesk 架构设计

## 分层架构

```
┌─────────────────────────────────────┐
│           UI 层 (WPF)              │
│  - 窗口、控件、样式、动画            │
│  - 用户交互、拖拽、悬浮效果          │
└─────────────────────────────────────┘
              ↓ 依赖
┌─────────────────────────────────────┐
│         BLL 层 (业务逻辑)           │
│  - 组件管理器 (WidgetManager)       │
│  - 系统监控服务                      │
│  - 农历计算服务                      │
│  - 数据模型定义                      │
└─────────────────────────────────────┘
              ↓ 依赖
┌─────────────────────────────────────┐
│         DAL 层 (数据访问)           │
│  - JSON 配置读写                    │
│  - 文件路径管理                      │
└─────────────────────────────────────┘
```

## 核心模块

### BaseWidgetWindow（组件基类）

所有组件窗口的基类，处理：
- 桌面层级控制（Win32 API）
- 拖拽移动
- 悬浮效果（透明度变化）
- 锁定功能
- 位置保存

### WidgetManager（组件管理器）

管理组件生命周期：
- 添加/删除组件配置
- 保存/加载配置
- 位置和大小更新

### 托盘管理（MainWindow）

系统托盘图标入口：
- 添加组件菜单
- 显示/隐藏所有组件
- 开机启动设置
- 退出应用

## 窗口层级

```
应用程序窗口 (最上层)
    ↓
OrionDesk 组件 (鼠标悬浮时临时提升)
    ↓
桌面图标 (SysListView32)
    ↓
桌面壁纸 (WorkerW，最底层)
```

## 交互逻辑

| 状态 | 层级 | 透明度 | 可交互 |
|------|------|--------|--------|
| 平时 | 底层 | 100% | ❌ 鼠标穿透 |
| 鼠标移入 | 临时提升到顶层 | 100% | ✅ 可操作 |
| 鼠标移出 | 降级回底层 | 100% | ❌ 鼠标穿透 |

## 数据存储

配置文件位置：`%LocalAppData%\OrionDesk\config.json`

```json
{
  "widgets": [
    {
      "id": "guid",
      "type": "clock|monitor|launcher|note",
      "position": { "x": 100, "y": 200, "width": 220, "height": 120 },
      "normalOpacity": 1.0,
      "hoverOpacity": 1.0,
      "settings": { ... }
    }
  ],
  "startWithWindows": false,
  "showAllWidgets": true
}
```
