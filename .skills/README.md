# OrionDesk - 项目状态

**项目名称**: OrionDesk（猎户座桌面）
**当前阶段**: 功能完善 + 稳定性验证
**最后更新**: 2026-08-07

## 项目简介

轻量级桌面小组件工具，支持时钟、系统监控、启动器、便签、文件夹映射等组件，固定在桌面图标层（应用程序下方）。
